# 工事受注入力 転記 GAS

Googleフォームで入力した工事受注を、確認用スプレッドシートを経て本番の
「受注一覧」「工事インデックス」へ転記するスクリプトです。
列の対応やファイル名はコードに書かず、毎回 **設定ファイル_YYMM** から読み込みます。

| 処理 | きっかけ | 内容 |
|---|---|---|
| GAS_1 | フォーム送信 | ❶工事受注入力 の新しい行を ❷確認_受注一覧・❸確認_工事インデックス へ書き込み、❶ の copyflag に日時を入れる |
| GAS_2 | 確認用ファイルのメニュー「カスタムメニュー ＞ コピー実行」／毎日深夜1時台 | ❷❸ の copyflag が空の行を本番へ書き込み、書けた行の copyflag に日時を入れる |

## 設置手順（初回だけ）

1. **確認_受注一覧_2611** を開き、「拡張機能 ＞ Apps Script」を開く
2. `juchu_transfer.gs` の中身をすべて貼り付けて保存する
3. **確認_工事インデックス_2611** でも 1〜2 を同じように行う
4. 確認_受注一覧 の Apps Script で、関数 `checkSettings` を選んで実行する
   - 初回は権限の確認が出るので許可する
   - 実行ログに5ファイルの URL・列の対応・次の書込み行が出れば、設定ファイルを正しく読めています
5. 同じ画面で関数 `setupTriggers` を **1回だけ** 実行する
   - フォーム送信時トリガーと、毎日深夜1時台のトリガーが作られます
   - 確認_工事インデックス 側では実行しないでください（二重に動きます）
6. 確認用ファイルを開き直すと、メニューに「カスタムメニュー ＞ コピー実行」が出ます

## 動作確認のしかた

1. フォームからテスト用の受注を1件送信する
2. ❷❸ の最後に1行ずつ追加され、❶ の Q列（copyflag）に日時が入ることを確認する
3. ❷ で「カスタムメニュー ＞ コピー実行」を押し、本番 受注一覧 の該当シート（例：27期11月）に載ることを確認する
4. ❸ でも同じように押し、本番 工事インデックス に載ることを確認する
5. 確認がすんだら、テスト行を本番・確認用・❶ から削除する

## 月が替わったとき

1. 確認用・本番・設定ファイルを新しい月の名前（例：_2612）で用意する
   - 確認用は「コピーを作成」で作ると、スクリプトも一緒にコピーされます
2. 両方の確認用ファイルの Apps Script で、先頭の `TARGET_MONTH` を新しい月（例：`'2612'`）に変える
3. フォームの回答先を新しい 工事受注入力 に変える
4. 確認_受注一覧 の Apps Script で `setupTriggers` をもう一度実行する

## 設定ファイルの読み方（実装で決めたこと）

設定ファイルに書かれていない部分は、次のように実装しています。

- **ファイルの探し方**：ファイル名で Google スプレッドシートを探します。同じ名前が複数あるときは、
  ドライブ名の最後の部分（例：`010_営業管理部`）と親フォルダー名が合うものを選びます。
  見つからない・決められないときは、設定ファイルの「ファイル情報」行の **G列にURL** を書けばそれを使います。
- **書き込む列**：「列番号」の行に列がある項目だけを書きます。copyflag は列番号の行に無いので、GAS_1 では書きません。
  書かない列（数式の列や手入力の列）には触れません。
- **書込み行**：A〜H 列に値も数式も無い行で、その下2行も空の最初の行（設定 5）。本番も同じです。
- **受注区分が2つ以上入っていたとき**：左の列（官公庁 → 民間 → ゼネコン → 同業）を優先します。
- **受注先の呼び名**：設定 3 のとおり「官公庁・民間・ゼネコン・同業」を書きます。
  本番の過去データは「元請・同業者」なので、合わせる場合は設定ファイルとコードの調整が必要です。
- **受注一覧のシート**：確認用には年が無いため、月が今月より後なら前年の受注とみなして期を決めます
  （例：2027年1月に 12月分をコピー → 27期12月）。該当シートが無い行はコピーせず、通知メールで知らせます。
- **金額**：「270,000」や全角数字も数値にして書きます。
- **深夜1時の自動実行**：設定 9 のとおり、確認前の行もコピーします。
- **エラー時**：スクリプトの持ち主にメールで知らせます。メニュー実行のときは画面に表示します。

## 注意

- GAS_1 で ❷ には書けて ❸ で失敗した場合、❶ の copyflag は空のままです。
  原因を直したあと `processPendingFormRows` を実行すると取り込み直せますが、❷ に同じ行が2つできるので片方を消してください。
- `processPendingFormRows` は ❶ で copyflag が空の行を **すべて** 取り込みます。
  設置前のテスト回答が残っている場合は、先に削除するか copyflag に日付を入れてください。
- 本番に載ったあとで確認用を直しても、本番には反映されません（本番を直接直してください）。
