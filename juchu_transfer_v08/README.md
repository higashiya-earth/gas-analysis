# 受注データ連携 GAS（設定ファイル_v08 用）

Googleフォームの回答（File1）を確認用（File2・File4）へ書き分け、確認後に本番（File3・File5・File6）へ移すスクリプトです。
ファイル名・シート名・列の対応・担当名は、毎回 **設定ファイル_v08** から読み込みます。

| 処理 | きっかけ | 内容 |
|---|---|---|
| GAS_Pri | フォーム送信 | File1 の新しい行を File2・File4 の空いた行へ書き、両方に書けたら File1 の Copyflag1 に日時 |
| GAS_Sec | メニュー「カスタムメニュー ＞ コピー実行」／毎日深夜1時台 | File2 → File3（期・月のシート）、File4 → File5、当初受注金額が 1,000,000 以上なら File4 → File6。書けた行の Copyflag2・Copyflag4 に日時 |

| | ファイル | シート |
|---|---|---|
| File1 | 工事受注入力_v08（回答） | フォームの回答 1 |
| File2 | 確認_受注一覧_v08 | 確認_受注一覧 |
| File3 | 受注一覧_v08 | 送信月のシート（例：27期11月） |
| File4 | 確認_工事インデックス_v08 | 工事Index |
| File5 | 工事インデックス_v08 | 先頭のシート（工事Index） |
| File6 | 注文書・注文請書チェックリスト | 27期 |

## 設置手順（初回だけ）

1. **設定ファイル_v08** を開き、「拡張機能 ＞ Apps Script」を開く
2. `コード.gs` の中身を消し、`juchu_transfer_v08.gs` の中身をすべて貼り付けて保存する
3. 関数 `checkSettings` を実行する（初回は権限を許可）
   - 実行ログに File1〜File6 の URL と列の対応が出れば、設定を正しく読めています
4. 関数 `setupTriggers` を実行する
   - フォーム送信時トリガーと、毎日深夜1時台のトリガーが作られます（何回実行しても1組だけ）
5. 設定ファイルを開き直すと、メニューに「カスタムメニュー ＞ コピー実行」が出ます

前の版（juchu_transfer.gs）を使っていた場合は、そちらの Apps Script で `removeTriggers` を実行して止めてください。

## 動作確認のしかた

1. フォームからテスト用の受注を1件送信する
2. File2・File4 の最後に1行ずつ追加され、File1 の T列（Copyflag1）に日時が入ることを確認する
3. File4 の指示書No・連番などを入れてから、設定ファイルで「カスタムメニュー ＞ コピー実行」を押す
4. File3（例：27期11月）・File5 に載り、File2 の K列・File4 の T列に日時が入ることを確認する
5. 当初受注金額が 1,000,000 以上のテストなら、File6 の A〜F 列にも載ることを確認する
6. 確認がすんだら、テスト行を各ファイルから削除する

## 設定ファイルの読み方

- A列「File1」〜「File6」の行：B列＝ドライブ名、D列＝ファイル名、F列＝シート名（空なら先頭シート）。G列に URL を書けばそれを優先します
- その下の「列名N」＝項目名、「File列N」（N＝自分の番号）＝書込み先の列、「File列M」（M＝別の番号）＝File M の転記元の列
  - 「FIle列」のような大文字・小文字の違いは区別しません
- 担当名変換テーブル：「担当名変換テーブル」と書かれたセルの1行下が見出し、2行下からデータ（左＝担当、右＝メールアドレス）

## 規則の実装（設定ファイルに書かれていない部分を含む）

- **1) 年・月・日・日付**：列名が「年」「月」「日」「日付」の項目は、転記元の欄が空でもタイムスタンプから作ります
- **2) 担当**：File1 の「担当」（C列）に値があればそれ、無ければメールアドレスを担当名に変換、無ければ「無し」
- **3) 元請担当者**：File1 の E列 → File4 の G列（設定のとおり）
- **4) 受注区分**：回答が1つだけのとき、元下＝その値、受注先＝その列の区分名（元請・民間・ゼネコン・同業者）。0個・2つ以上は空欄
- **5) 入力確認**：文字列に「C)」があれば File4 の Q列（同一工事）に「○」、「D)」があれば R列（撮影）に「○」
  - 選択肢の文言に含まれる「C」「D」を誤って拾わないよう、「C)」「D)」の形で判定します
- **金額**：「1,500,000」のような文字列も数値にして書きます
- **書込み行**：A〜H 列（File6 は A〜F 列）に値も数式も無い行で、その下2行も空の最初の行。間の列（数式・手入力）には触れません
- **File3 のシート**：File2 の J列（年）と A列（月）から決めます（27期＝2026年7月〜2027年6月）。シートが無い行はコピーせず、メールで知らせます（28期のシートは事前に作成してください）
- **File6**：当初受注金額（File4 の S列）が 1,000,000 以上の行だけ。File6 に同じ指示書No・連番の行があれば書きません（指示書No が空なら判定しません）
- **Copyflag4**：File5 と File6（対象のときだけ）の両方に書けたときに付けます。File6 だけ書けて File5 で止まった行は、次回 File6 を飛ばして File5 だけ書き直します
- **File6 の「最終確認」（M列）**：転記元の指定が無いため書きません

## 注意

- File4 の既存行（11/2〜11/5 分）は Copyflag4 が入っているため、File5・File6 には流れません
- `processPendingFormRows` は File1 で Copyflag1 が空の行を **すべて** 取り込みます。11/7・11/8 のテスト回答が残っている場合は、先に削除するか Copyflag1 に日付を入れてください
- 実行するアカウントには、共有ドライブ3つ（310・010・100）の編集権限が必要です
