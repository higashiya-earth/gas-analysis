# 受注データ連携 GAS（設定ファイル_v08 用）

Googleフォームの回答（File1）を確認用（File2・File4）へ書き分け、確認後に本番（File3・File5・File6・File7）へ移すスクリプトです。
ファイル名・シート名・列の対応・担当名は、実行のたびに **設定ファイル_v08** から読み込みます。

| 処理 | きっかけ | 内容 |
|---|---|---|
| GAS_Pri | フォーム送信 | File1 の新しい行を File2・File4 の空いた行へ書き、両方に書けたら File1 の Copyflag1 に日時 |
| GAS_Sec | メニュー「カスタムメニュー ＞ コピー実行」／毎日深夜1時台 | File2 → File3（期・月のシート）、File4 → File5・File7、当初受注金額が 1,000,000 以上なら File4 → File6。書けた行の Copyflag2・Copyflag4 に日時 |
| サイト表示 | コピー実行・深夜のあと／1時間ごと／メニュー「サイト表示を更新」 | File5 の工事Index を、見た目ごとシート「サイト表示」へ写す（A列 ★ の行から下、× の行は除く） |

| | ファイル | シート | 見出し |
|---|---|---|---|
| File1 | 工事受注入力_v08（回答） | フォームの回答 1 | 1行目（A〜S、S＝Copyflag1） |
| File2 | 確認_受注一覧_v08 | 確認_受注一覧 | 3行目（K＝Copyflag2） |
| File3 | 受注一覧_v08 | 送信月のシート（例：27期11月） | 3行目 |
| File4 | 確認_工事インデックス_v08 | 工事Index | 1行目（T＝現場詳細、U＝Copyflag4） |
| File5 | 工事インデックス_v08 | 先頭のシート（工事Index） | 1行目 |
| File6 | 注文書・注文請書チェックリスト | 27期 | 7行目 |
| File7 | 工事現場詳細_v08 | 現場詳細 | 2行目 |

## 設置手順（初回だけ）

1. GAS を入れるファイル（設定ファイル_v08 や 確認_工事インデックス_v08 など）を開き、「拡張機能 ＞ Apps Script」を開く
2. `コード.gs` の中身を消し、`juchu_transfer_v08.gs` の中身をすべて貼り付けて保存する
3. 関数 `checkSettings` を実行する（初回は権限を許可）
   - 実行ログに File1〜File7 の URL・見出しの行・次の書込み行・列の対応が出れば、設定を正しく読めています
4. 関数 `setupTriggers` を実行する
   - フォーム送信時トリガーと、毎日深夜1時台のトリガーが作られます（何回実行しても1組だけ）
5. GAS を入れたファイルを開き直すと、メニューに「カスタムメニュー ＞ コピー実行／設定の確認」が出ます
   - 「設定の確認」の1行目に `GAS：v08-サイト表示対応 2026-11-14` と出れば、最新のコードが動いています
   - 前の版から貼り替えたときも、`setupTriggers` をもう一度実行してください（サイト表示の1時間ごとのトリガーが加わります）

- 別の場所に前の版の GAS を入れていた場合は、そちらで `removeTriggers` を実行して止めてください（トリガーが2組あると二重に書き込みます）
- コード先頭の `SETTINGS_FILE_ID` に設定ファイル_v08 のIDを書いてあるので、どのファイルの Apps Script に貼っても動きます。メニューは貼ったファイルに出ます

## Googleサイトに工事インデックスを表示する（サイト表示）

File5（工事インデックス_v08）の中に、表示用のシート「**サイト表示**」を GAS が作り、工事Index と**同じ見た目**（書式・リンク・列の幅・行の高さ・固定行・枠線の表示・非表示の列）で写します。

| 工事Index の A列 | 意味 |
|---|---|
| ★ | この行から下を表示する（1か所だけ。月が変わったら新しい月の 001 の行へ移す） |
| × | この行は表示しない（テストの行など） |

- 見出し（1〜3行目）はいつも表示します。★ が無ければ、4行目（最初のデータ行）から全部を表示します
- ★ の印はサイト表示には出しません
- ★・× は **データのある行にだけ** 入れてください（空行に入れると、GAS がその行を書込み先に使わなくなります）
- 更新のタイミング：コピー実行・深夜のコピーのあと、1時間ごと、メニュー「カスタムメニュー ＞ サイト表示を更新」
- サイト表示は GAS が毎回書き直します。**サイト表示を直接直さず**、工事Index のほうを直してください

### Googleサイトへの貼り方（最初に1回）

1. 「カスタムメニュー ＞ サイト表示を更新」を1回押して、シート「サイト表示」を作る
2. 工事インデックス_v08 で「ファイル ＞ 共有 ＞ ウェブに公開」→「埋め込む」タブ →「ドキュメント全体」を「**サイト表示**」に変える
3. 「（会社のドメイン）内のユーザーのみ」にチェックして「公開」
4. 埋め込みコードを、Googleサイトの「挿入 ＞ 埋め込む ＞ 埋め込みコード」に貼る

- GAS はシートを作り直さず中身だけ入れ替えるので、一度貼った埋め込みはそのまま使えます
- 設定ファイルの File5 の F列（シート名）には「工事Index」と書いておくのが確実です。空欄でも、GAS は「サイト表示」には書き込みません

## 日付とタイムゾーン

- 日付・Copyflag は **日本時間の文字列**（例：`2026/11/13`、`2026/11/13 18:18:25`）で書きます。各ファイルのタイムゾーン設定が違っても、日付はずれません
- ただし、ファイルのタイムゾーンが日本以外だと、手入力した日時の表示がずれることがあります。「設定の確認」で注意が出たファイルは「ファイル ＞ 設定 ＞ タイムゾーン」を **(GMT+09:00) 東京** にしてください

## File7 に入らなかった行を取り戻すとき

古い版の GAS で「コピー実行」した行は、File5・File6 には入っても File7 には入らず、Copyflag4 が付いています。

1. 最新のコードに貼り替え、「設定の確認」で版を確かめる
2. File4（確認_工事インデックス）で、その行の **Copyflag4（U列）を消す**
3. 「カスタムメニュー ＞ コピー実行」を押す
   - File5・File6 は同じ行がすでにあるので書かれず、File7 にだけ書かれて Copyflag4 が付きます

## 設定を変えたとき

| 変えたもの | 必要な操作 |
|---|---|
| ファイル名・シート名・列の対応・担当名変換テーブル | 何もしなくてよい（次の実行から反映） |
| File1（工事受注入力）を別のファイルにした | `setupTriggers` を実行し直す |
| 設定ファイルそのものを別のファイルにした | コード先頭の `SETTINGS_FILE_ID` を新しいIDに書き換える |
| 変えたあとの確認 | `checkSettings` を実行し、7つのファイルが見つかるかを見る |

## 動作確認のしかた

1. フォームからテスト用の受注を1件送信する
2. File2・File4 の最後に1行ずつ追加され、File1 の S列（Copyflag1）に日時が入ることを確認する
3. 必要なら File4 の指示書No・連番などを入れてから、「カスタムメニュー ＞ コピー実行」を押す
4. File3（例：27期11月）・File5・File7 に載り、File2 の K列・File4 の U列に日時が入ることを確認する
   - File7 の現場詳細が折り返され、行の高さが内容に合っていること
5. 当初受注金額が 1,000,000 以上のテストなら、File6 の A〜F 列にも載ることを確認する
6. 確認がすんだら、テスト行を各ファイルから削除する

## 設定ファイルの読み方

- A列「File1」〜「File7」の行：B列＝ドライブ名、D列＝ファイル名、F列＝シート名（空なら先頭シート）。G列に URL を書けばそれを優先します
  - ファイルは D列の名前で探します。同じ名前が複数あるときだけ、B列の最後のフォルダー名で選びます
  - File3 の F列は使いません（シートは日付から決まります）。空欄のままにしてください
  - File7 は書いてあれば使います（無ければ File7 へのコピーをしません）
- その下の「列名N」＝項目名、「File列N」（N＝自分の番号）＝書込み先の列、「File列M」（M＝別の番号）＝File M の転記元の列
  - 「FIle列」のような大文字・小文字の違いは区別しません
- 担当名変換テーブル：「担当名変換テーブル」と書かれたセルの1行下が見出し、2行下からデータ（左＝担当、右＝メールアドレス）

## 規則の実装（設定ファイルに書かれていない部分を含む）

- **1) 年・月・日・日付**：列名が「年」「月」「日」「日付」の項目は、転記元の欄が空でもタイムスタンプから作ります
- **2) 担当**：File1 の「担当」（C列）に値があればそれ、無ければメールアドレスを担当名に変換、無ければ「無し」
- **3) 元請担当者**：File1 の E列 → File4 の G列（設定のとおり）
- **4) 受注区分**：回答が1つだけのとき、元下＝その値、受注先＝その列の区分名（元請・民間・ゼネコン・同業者）。0個・2つ以上は空欄
- **5) 入力確認**：文字列に「C)」があれば File4 の Q列（同一工事）に「○」、「D)」があれば R列（撮影）に「○」
  - 選択肢の文言に含まれる「C」「D」を誤って拾わないよう、「C)」「D)」の形で判定します
- **6) 空欄**：指示書No などが空の行も、空欄のまま移します
- **金額**：「1,500,000」のような文字列も数値にして書きます
- **書込み行**：見出し行より下で、A〜H 列（File6 は A〜F、File7 は A〜G）に値も数式も無い行のうち、その下2行も空の最初の行。間の列（数式・手入力）には触れません
  - 見出し行は、上から15行のうち設定ファイルの列名が半分以上並んでいる行です。新しいシートの上の方に空行があっても、見出しより上には書きません
- **File3 のシート**：File2 の J列（年）と A列（月）から決めます（27期＝2026年7月〜2027年6月）。シートが無い行はコピーせず、メールで知らせます（28期のシートは事前に作成してください）
- **File6**：当初受注金額（File4 の S列）が 1,000,000 以上の行だけ。「最終確認」（M列）は転記元の指定が無いため書きません
- **File7**：毎回書きます。現場詳細（G列）は折り返し表示にし、行の高さを内容に合わせます
- **Copyflag4**：File5・File6（対象の行だけ）・File7 がすべて書けたときに付けます
  - 途中で止まった行や Copyflag4 を消した行は、次回やり直します。File5・File6・File7 とも同じ行がすでにあれば書きません（指示書No があれば 指示書No・連番で、空なら書く列すべての値で比べる）

## 注意

- `processPendingFormRows` は File1 で Copyflag1 が空の行を **すべて** 取り込みます。試験回答が残っている場合は、先に削除するか Copyflag1 に日付を入れてください
- 実行するアカウントには、共有ドライブ3つ（310・010・100）の編集権限が必要です
