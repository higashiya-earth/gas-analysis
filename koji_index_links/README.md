# 工事インデックス リンク一覧 GAS

スプレッドシート「工事インデックス リンク一覧」に貼る GAS です（転記用・サイト表示用の GAS とは別）。
シート「設定」の年ごとのフォルダーから「工事インデックス　YYYY年M月」のファイルを探し、
シート「URL一覧」の B〜H列を書き直します。表示用シート（2024〜2026年・2027〜2029年）は数式なので、自動で変わります。

## 設置（最初に1回）

1. 「工事インデックス リンク一覧」を開き、「拡張機能 ＞ Apps Script」
2. `コード.gs` の中身を消し、`links_update.gs` をすべて貼って保存
3. 関数 `setupLinksTrigger` を実行（初回は権限を許可）
   - URL一覧が書き直され、毎日 朝5時台の自動更新が設定される
4. ファイルを開き直すと、メニュー「リンク一覧 ＞ 今すぐ更新」が出る

## 決まりごと

- 設定シート：A＝年、B＝区分（空欄 または R）、C＝フォルダーの URL。2行目から、年が空の行まで読む
- 載せるファイル：名前に「工事インデックス」と「YYYY年M月」があり、年が設定の年と同じもの（全角数字も可）
- 載せないファイル：名前に「コピー」があるもの。同じフォルダーに同じ年月が2つあれば、更新日の新しい方だけ
- 並び：年 → 区分（空欄が先、R が後）→ 月。表示用シートは同じ年月なら下の行（R）を使う
- URL一覧の A列（キー）は数式なので触らない。B〜H列は毎回書き直す（手で足した行も消える）
- フォルダーが開けないとき：メニューでは結果に表示、自動更新ではエラーとして記録（見つかった分は書く）
