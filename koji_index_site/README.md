# 工事インデックス_v08 サイト表示 GAS

工事インデックス_v08 にだけ貼る GAS です（転記用の `juchu_transfer_v08.gs` とは別。転記用は変えません）。
シート「工事Index」を、**見た目ごと**シート「サイト表示」へ写し、Googleサイトにはこのシートを埋め込みます。

写すもの：値・書式・セル色・文字色・太字・リンク・セルの結合・条件付き書式・列の幅・行の高さ・固定行・枠線の非表示・隠した列

| 工事Index の A列 | 意味 |
|---|---|
| ★ | この行から下を表示（1か所だけ。月が変わったら新しい月の 001 の行へ移す） |
| × | この行は表示しない（テストの行など） |

- 1〜3行目の見出しはいつも表示。★ が無ければ4行目から全部
- ★ の印はサイト表示には出ない
- ★・× はデータのある行にだけ入れる（空行に入れると、転記用 GAS がその行を書込み先に使わない）

## 設置（最初に1回）

1. 工事インデックス_v08 を開き、「拡張機能 ＞ Apps Script」
   - 転記用の GAS がこのプロジェクトに入っていないことを確かめる（入っていると onOpen が重なる）
2. `コード.gs` の中身を消し、`site_display.gs` をすべて貼って保存
3. 関数 `setupSiteTrigger` を実行（初回は権限を許可）
   - 「サイト表示」シートが工事Index の右にでき、1時間ごとの自動更新が設定される
4. 設定ファイル_v08 の File5 の行の F列（シート名）に「工事Index」と入力
   - 空欄だと転記用 GAS は先頭のシートに書くため。「サイト表示」を先頭に動かさないこと
5. 「ファイル ＞ 共有 ＞ ウェブに公開」→「埋め込む」→「サイト表示」→「（会社のドメイン）内のユーザーのみ」→「公開」
6. 埋め込みコードを Googleサイトの「挿入 ＞ 埋め込む ＞ 埋め込みコード」に貼る

## 更新されるとき

- A列の ★・× を入力・削除したとき（すぐ）
- 1時間ごと（転記用 GAS が書き足した行を反映）
- メニュー「サイト表示 ＞ 今すぐ更新」

シートは作り直さず中身だけ入れ替えるので、一度貼った埋め込みはそのまま使えます。
「サイト表示」は毎回書き直されるので、直接直さず工事Index のほうを直してください。
止めるときは `removeSiteTrigger` を実行します。
